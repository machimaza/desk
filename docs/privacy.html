개인정보처리방침

시행일 2026년 8월 25일

마치마자(이하 “운영자”)는 이용자의 개인정보를 소중히 다룹니다. 이 방침은 운영자가 어떤 정보를 다루고 다루지 않는지 밝힙니다.

1. 이 사이트가 수집하지 않는 것

이 웹사이트는 정적 페이지로만 이루어져 있습니다. 회원가입, 로그인, 댓글, 문의 양식이 없습니다. 따라서 운영자는 이 사이트를 통해 이용자의 개인정보를 수집하지 않습니다.

다만 이 사이트는 GitHub Pages 에서 제공되며, 그 과정에서 GitHub 이 접속 기록(IP 주소 등)을 자체 정책에 따라 처리할 수 있습니다. 자세한 내용은 GitHub 의 개인정보처리방침을 따릅니다.

2. 업로드 도구가 다루는 정보

운영자는 자신이 만든 영상과 글을 자신의 채널에 올리기 위해 자체 제작한 도구를 사용합니다. 이 도구는 운영자 본인의 계정에만 접근하며, 제3자에게 제공되지 않습니다.

서비스사용하는 권한무엇에 쓰나
YouTube Data API youtube.upload 운영자 본인 채널에 영상을 업로드
Threads API threads_basic
threads_content_publish		 운영자 본인 계정에 게시물 발행

이 도구는 다음을 하지 않습니다.

  • 다른 이용자의 계정에 접근하거나 대신 게시하지 않습니다
  • 시청자·구독자·팔로워의 개인정보를 조회하거나 저장하지 않습니다
  • 취득한 정보를 제3자에게 판매하거나 제공하지 않습니다
  • 취득한 정보를 광고나 인공지능 모델 학습에 사용하지 않습니다

접근에 사용하는 인증 정보(토큰)는 운영자의 코드 저장소 비공개 설정 (GitHub Actions Secrets)에 보관되며 공개되지 않습니다. YouTube API 를 통해 얻은 데이터의 사용은 YouTube 서비스 약관 및 Google 개인정보처리방침을 따릅니다.

3. 권한 철회

운영자는 Google 계정 권한 설정에서 이 도구의 접근 권한을 언제든지 철회할 수 있습니다. 철회하면 도구는 더 이상 채널에 접근하지 못합니다.

4. 콘텐츠에 관하여

이 사이트와 각 채널에 실린 정보는 참고용입니다. 제도와 금액은 바뀔 수 있으므로, 정확한 내용은 각 소관 기관에서 확인하셔야 합니다. 운영자는 의료·법률·금융 자문을 제공하지 않습니다.

5. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
