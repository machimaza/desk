# 채널 소개글 — 6개 채널

핸들·주소의 출처는 `channels.json` 입니다. 여기 문구만 손으로 붙여넣습니다.
자동 입력은 하지 않습니다 — 네이버·티스토리는 자동화가 약관 위반이고,
인스타·쓰레드는 소개글을 API 로 바꿀 수 없습니다.

---

## 이 소개글의 원칙 넷

**하나. 슬로건은 고정입니다.**
`마침 필요한 정보를, 알맞게` — 홈페이지가 쓰는 문구이고, 여섯 곳 **첫 줄에 그대로** 들어갑니다.
소개글마다 다른 말로 바꾸면 슬로건이 아니라 그때그때 지은 문장이 됩니다.

**둘. 이름 이야기로 엽니다.**
`마침맞다` — 어떤 경우나 기회에 꼭 알맞다. 경상도·전남 방언으로 `마치맞다`.
그 말에서 온 이름입니다. 설명하지 않으면 그냥 뜻 모를 네 글자입니다.
**설명하면 채널이 무엇을 하려는지가 이름 안에 다 들어 있습니다.**

**셋. 다루는 것을 못 박지 않습니다.**
`건강보험 · 세금 · 지원금` 을 명시하면 카테고리를 열 때마다 여섯 곳을 다시 고쳐야 하고,
그 전까지 소개글이 거짓말이 됩니다. `categories.json` 에 국민연금·고용보험이 이미
`예정` 으로 들어 있습니다. 그래서 **"궁금한 것"** 이라는 넓은 말로 두고,
길이가 허락하는 유튜브에서만 예시를 듭니다.

**넷. 이모지는 줄머리에만.**
문장 속에 섞으면 산만하고, 줄머리에 하나씩 두면 **목록이 눈에 들어옵니다.**
네 개만 돌려 씁니다 — 🔎 무엇을 하나 · 📌 어떻게 하나 · 🧾 근거 · 🔗 링크.
채널마다 다른 이모지를 쓰면 같은 채널로 안 보입니다.

### 넣지 않는 것

| | 왜 |
|---|---|
| 자격·직함 (세무사·노무사 등) | 사실이 아니면 사칭입니다 |
| "무조건 받는 돈" · "모르면 손해" | 과장·불안 조성. 본문에서 린터가 막는 표현입니다 |
| 종목·수익률 이야기 | 금융소비자보호법 제22조 주체 요건 위험 |
| "구독과 좋아요" | 지면을 먹고 신뢰를 깎습니다 |
| 채널 6개 나열 | **허브 하나만** 가리킵니다 |

> **허브 주소를 먼저 정하세요.** 지금은 `machimaza.github.io/desk/` 입니다.
> `/desk/` 가 저장소 이름 그대로라 임시 페이지처럼 읽힙니다.
> `machimaza.github.io` 라는 이름의 저장소를 새로 만들어 허브만 옮기면 무료로 짧아집니다.
> **여섯 곳에 붙이기 전에** 정하는 편이 낫습니다.

## 바꿀 때

**여섯 개를 같이 바꿉니다.** 한 곳만 고치면 같은 채널로 안 보입니다.
핸들·주소가 바뀌면 `channels.json` 을 먼저 고치고 `test_brand.py` 를 돌립니다.

**카테고리를 열 때 이 파일은 안 고쳐도 됩니다.** 유튜브 설명의 예시 줄만,
새 분야가 실제로 여러 편 쌓인 뒤에 한 번 손봅니다.

## 소개글의 이모지는 글 안으로 들어오지 않습니다

**소개글은 프로필이고, 글·영상·카드는 콘텐츠입니다.** 프로필에서 이모지가 하는 일
(줄 구분·시선 유도)을 본문에서는 조판이 대신합니다.
`lint_style.py` 와 렌더러 규칙(9장)은 그대로 둡니다.
